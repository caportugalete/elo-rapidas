# Portugaleteko Xake Taldea - Sistema ELO de Rápidas

Portal oficial de clasificación y fichas de socios del **Club de Ajedrez Portugalete (Portugaleteko Xake Taldea)**.

🌐 **Portal Web en Vivo**: [https://caportugalete.github.io/elo-rapidas/](https://caportugalete.github.io/elo-rapidas/)

---

## Características del Portal Web
- **Ranking Oficial en Tiempo Real**: clasificaciones actualizadas según normativa FIDE de partidas rápidas (K=10).
- **Fichas Individuales de Socios**:
  - Récords personales (Peak ELO, mejor performance, efectividad).
  - Gráfico evolutivo de ELO torneo a torneo.
  - Desglose de trayectoria completa.
- **Buscador en vivo** por jugador, apellidos o título.
- **Filtros interactivos** (Activos, Inactivos, Top 3).
- **Copia con 1-clic** para resúmenes accesibles por WhatsApp.
